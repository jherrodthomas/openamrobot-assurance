## 1. Purpose

How work products and code are verified by review: review types, entry and exit criteria, checklists per work product type, independence levels, and the record format that confirmation measures reuse.

## 2. Review types

Desk check, walkthrough, inspection, tool-assisted analysis review; which applies to which class.

## 3. Independence levels

I0–I3 as in WP-M-06 §3; I1 minimum for SR-A and SR-Q; self-review is I0.

## 4. Entry and exit criteria

CI green, header complete, links resolve, trace IDs exist; all findings resolved or tracked.

## 5. Checklists

Per work product type: risk assessment, safety functions and PLr, SRS, architecture, PL calculation, software requirements, test specifications, safety case.

## 6. Review record template

Identifier, object, reviewer and independence, date, method, findings, outcome; used for confirmation records too.
