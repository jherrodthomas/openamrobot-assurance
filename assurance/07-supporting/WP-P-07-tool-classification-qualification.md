## 1. Purpose

Classification and qualification of the software tools whose output enters a safety work product or a binary: build tools, static analysers, test frameworks, SISTEMA, the figure generators, the AI assistant; tool impact, error detection and the resulting confidence level (IEC 61508-3 T1–T3).

## 2. Tool list

TL-nn: name, version, use, class, qualification evidence.

## 3. Classification method

Impact on the output, probability of detecting an error, resulting class; qualification by validation, proven use or developer evidence.

## 4. AI assistant

Classification per WP-M-02 §3.3 OI-4.
