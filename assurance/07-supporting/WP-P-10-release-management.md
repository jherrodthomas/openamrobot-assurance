## 1. Purpose

Release management: what a release of the fork is (tagged commits across the repositories, pinned images, a parameter set, a technical documentation state), the release checklist, the baseline tag, signed images, the update procedure and the declaration of conformity draft that accompanies a release.

## 2. Release contents and naming

Tags, manifest, SBOM, parameter set, documentation baseline.

## 3. Release checklist

Gate G5 passed, assessment report, open anomalies, declaration draft, information for use.

## 4. Updates

Signed, versioned, rollback; security update management (62443-4-1 SUM).
