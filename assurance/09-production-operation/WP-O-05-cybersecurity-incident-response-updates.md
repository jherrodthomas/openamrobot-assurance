## 1. Purpose

Cybersecurity incident response, vulnerability management and software updates (IEC 62443-4-1 DM and SUM): intake through private vulnerability reporting, triage, fix, advisory, signed update, and the watch on upstream and dependency advisories.

## 2. Vulnerability intake

GitHub private vulnerability reporting per [SECURITY.md](../../SECURITY.md); response times.

## 3. Defect management

DM-1…DM-6: receive, review, assess, address, disclose, periodic review.

## 4. Update management

SUM-1…SUM-5: qualification, documentation, dependent components, delivery, timeliness.

## 5. Monitoring

SBOM scanning, upstream advisories, ROS 2 security announcements.
